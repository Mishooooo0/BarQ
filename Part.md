## Collaboration rules

- Each owner records scope, deliverables, dependencies, and handoffs here.
- No one should mark a part **Done** without linked evidence (commit, pull request, test output, or acceptance sign-off).
- Use `Plan.md` for roadmap and milestones and `Updates.md` for the append-only history.
- `main` is the canonical source for these three documents; distribute documentation changes to active branches while preserving each branch's code and unrelated files.
- When two branches modify shared docs, reconcile changes deliberately instead of blindly replacing another contributor's work.
